# BBA Main Project Website (Campus Connect)

This is a static website prototype for a BBA main project.

## Run locally

Because this is a static HTML/CSS/JS site, you can run it in either of these ways:

### Option 1: Open directly in browser
1. Go to the project folder.
2. Double-click `index.html`.

### Option 2: Run a local server (recommended)
From the project root:

```bash
python3 -m http.server 8000
```

Then open:

- `http://localhost:8000`

## Project files

- `index.html` — main webpage structure
- `styles.css` — styling and responsive layout
- `script.js` — mobile menu and contact form behavior
